# Week 01 — Passive OSINT & Subdomain Enumeration

## Overview
Focused on passive reconnaissance against hackthissite.org using OSINT tools, without any direct active probing of the target.

## Tools Used
- Subfinder, Assetfinder, Amass — subdomain enumeration
- crt.sh — certificate transparency lookups
- Google Dorking — exposed files, login pages, sensitive directories
- GitHub leak analysis — hardcoded credentials
- GoWitness — visual web reconnaissance

## Key Findings
- Successfully enumerated subdomains using multiple passive tools
- Documented 35 screenshots across the full reconnaissance workflow
- Delivered a professional PDF report (dark cyber-themed, built with ReportLab)
